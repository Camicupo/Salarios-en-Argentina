# Salarios en Argentina
 En primer lugar, luego de un procesamiento de la base correspondiente se procede a crear un mapa coroplético detallando salario promedio por departamento en la Argentina.

 En segundo lugar, se cargan las bases correspondientes para ver el salario promedio por actividad económica y se procede a graficar las actividades que tienen los salarios más bajos. 

 En tercer lugar, se observan los sectores de actividad económica con mayor salario y su modificación a través del tiempo.
